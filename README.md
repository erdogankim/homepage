# erdogan.kim — taslak arşivi

Yazılım mimarı, danışmanı ve eğitmeni **Erdoğan Öztürk** için kişisel site tasarım çalışmalarının yerel arşivi. Her dosya kendi içinde bağımsız, tek tıkla tarayıcıda açılır.

Başlamak için `index.html` dosyasını aç — oradan hepsine ulaşırsın.
